# پل اسنپ‌فود دارینو (مک)

اسنپ‌فود فقط به IP ایران جواب می‌دهد و سرور دارینو (Vercel) خارج از ایران است. این پل روی مک خودتان،
از مسیر VPN ایران، جستجوی رستوران‌ها، کافه‌ها، شیرینی‌فروشی‌ها و کترینگ‌ها را برای «دستیار و راهنمای خرید» انجام می‌دهد.

## امنیت

- **هیچ پورتی باز نمی‌کند**؛ فقط خودش به `dariiino.vercel.app` و `snappfood.ir` وصل می‌شود.
- داخل **sandbox مک** اجرا می‌شود: خواندن/نوشتن پوشهٔ خانه (Library، کروم و افزونه‌ها، Keychain، کیف پول‌ها،
  Downloads، Documents، Desktop، `.ssh`) و اجرای هر برنامهٔ دیگر **ممنوع** است؛ فقط پوشهٔ `~/.darino-bridge` خودش.
- هیچ پکیج خارجی ندارد؛ فقط Node. کد: `bridge.mjs`.
- آدرس اسنپ‌فود داخل خود پل ثابت است؛ سرور فقط «کلمهٔ جستجو + مختصات مرکز شهر» می‌فرستد که دوباره چک می‌شود.
- کلید پل فقط اجازهٔ «گرفتن صف جستجو و فرستادن نتیجه» را دارد؛ نه دیتابیس، نه حساب‌ها.

## نصب (یک بار)

۱. در Terminal (با VPN ایران روشن):

```bash
bash ~/Downloads/Darino-shop/tools/snappfood-bridge/install.sh https://dariiino.vercel.app
```

کلید پل خودکار در کلیپ‌بورد کپی می‌شود.

۲. در Vercel: پروژهٔ **dariiino** ← **Settings** ← **Environment Variables** ← **Add**
   - Key: `SHOP_RELAY_KEY` — Value: کلید کپی‌شده (Cmd+V) — Environment: **Production** ← **Save**
   - سپس **Deployments** ← آخرین Deploy ← **⋯** ← **Redeploy**

۳. بررسی:

```bash
node ~/.darino-bridge/bridge.mjs --test     # باید «✅ مسیر ایران درست است» بنویسد
tail -n 20 ~/.darino-bridge/bridge.log      # گزارش پلِ در حال اجرا
```

اگر `--test` ✅ بود ولی در `bridge.log` «❌ 403» آمد، X-VPN ترافیک برنامه‌های پس‌زمینه را از ایران عبور نمی‌دهد:
در X-VPN حالت **Global / همهٔ برنامه‌ها** را انتخاب کنید (Split Tunneling خاموش).

## استفاده

در دارینو ← «دستیار و راهنمای خرید» بنویسید، مثلاً «ارزان‌ترین پیتزای تخفیف‌دار در اهواز» یا «بهترین آیس‌لاته در کافه‌های اهواز».
پاسخ رستوران‌ها حدود ۵ تا ۲۰ ثانیه طول می‌کشد. اگر مک خاموش یا VPN قطع باشد، دستیار خودکار لینک مستقیم اسنپ‌فود را نشان می‌دهد.

## حذف کامل

```bash
bash ~/Downloads/Darino-shop/tools/snappfood-bridge/uninstall.sh
```

و `SHOP_RELAY_KEY` را از Vercel پاک کنید.
